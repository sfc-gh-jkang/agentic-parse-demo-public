# Security Policy

Please do not report security issues in public GitHub issues.

Report a suspected vulnerability, or a credential or account detail accidentally committed to this repository, by email to the owner: John Kang, john.kang@snowflake.com. Include the file or commit, what you found, and how to reproduce it. You will get an acknowledgement, and fixes are made on a best-effort basis.

This repository is a demo. It deploys objects into your own Snowflake account using your own credentials; it contains no credentials of its own.
